# Scene Production Package Method

## Purpose

This layer converts the four world dossiers and the completed 102-scene screenplay into buildable sequence packages for art direction, sets, locations, props, costume, hair and makeup, special effects, crowds, animals and continuity.

## Package rule

Every package must retain:

1. Tamil HWT anchors.
2. Exact screenplay scene range.
3. Principal sets and travel paths.
4. Hero-prop custody and condition.
5. Costume/body state at entry and exit.
6. Crowd, animal and ritual systems.
7. Historical research holds.
8. Storyboard priority.

A package is not approved for build merely because it is visually attractive. It must pass source, continuity, safety, labour visibility and religious-specificity review.

## Twelve-package structure

The register at `evidence/production_design_sequence_packages.csv` divides the film into three packages for each world:

- Pukār: household/art; festival/rupture; departure.
- Road: Kāviri; pālai/ritual; Madurai threshold.
- Madurai: competence/failure; body/court/proof; fire/transition.
- Vañci: hill witness; state expedition; consecration/institution.

## Department gates

- **Art:** geography and working systems are credible.
- **Props:** source state and custody are traceable.
- **Costume:** material condition follows elapsed story time.
- **SFX/VFX:** no effect changes moral causality.
- **Ritual/performance:** source-specific practice is not flattened.
- **Safety:** water, animals, crowds, weapons, fire and body effects have specialist approval.
- **Storyboard:** entrances, exits, eyelines, object reveals and transition matches are boardable.
